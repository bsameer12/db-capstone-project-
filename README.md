# Meta Database Engineer Capstone Project (MySQL · Python · Tableau)

End-to-end relational database engineering, SQL optimization, Python client integration, and BI analytics project completed for the **Meta Database Engineer** certification.

---

## Modules & Contents

- **`ER Diagram/` & `Forward_Engineering_ER/`** — Entity-Relationship modeling and forward-engineered MySQL schema scripts.
- **`Insert/` & `Insert_Update_Delete/`** — Relational data seeding and CRUD manipulation scripts.
- **`View_Join_Sub-Query/`** — Analytical SQL views, multi-table joins, and nested subqueries.
- **`Stored_Procedure-Prepared_statement/`** — Parameterized prepared statements and reusable MySQL stored procedures.
- **`MySQL Transactions/`** — ACID-compliant transactional workflows.
- **`Python Database Client/`** — Python application connecting to and querying the MySQL database.
- **`Data Visulization Using Tabeula/`** — Interactive BI visualizations and dashboards built in **Tableau**.

---

## Tech Stack

- **Database:** MySQL (Stored Procedures, Prepared Statements, Views, Transactions, ER Modeling)
- **Programming:** Python (Database Client Connector)
- **Analytics & BI:** Tableau
